# C# Automation training course

Here is the C# automation course for training purposes. If you want practice, go for it.
There are several projects in the solution. You'll have an ability to pull repository from remove, push option is blocked. In order to start working, follow the next instructions:
  1. Clone the remote repository to your local machine.
  2. Open the solution via Visual Studio or Raider: ProgrammingTasks/ProgrammingTasks.sln.
  3. Open project as per steps below and have fun.

## Theory
The first step is to gain basic knowledge in C# language. Look at videos from the link below and practicing with the author. 
<br>[Basic knowledge](https://learn.microsoft.com/en-us/shows/csharp-fundamentals-for-absolute-beginners).
<br>It will help you to install Visual Studio and set up IDE for programming. Gain knowledge in language structure as well as classes, namespaces and different data types, simple operators as loops, conditions. 

## Programming tasks
Programming tasks are located here: ProgrammingTasks.
Now there are four types of tasks: Arrays, Condition operator, Loop operator, Matrix. You can do them is any order as you want, but suggestion in the following:
  1. Condition operator.
  2. Loop operator.
  3. Arrays.
  4. Matrix.

<br>All needed documentation you can find in the tasks files under 'Documentation' part. Don't hesitate to use it and ask me any questions if occur.

## LINQ tasks
LINQ tasks are located here: LINQTasks.
<br>There are 5 files, which split up by methods: All(), Any(), Contains(), Select(), Where(). Each file includes source documentation, several methods and tests. Please, do NOT update tests. Each method in the file is your task. You should add your code after 'var result =' expression. After that you can run the test, if it passed, all good, if not - make updates in your code. In order to launch test follow the steps below:
1. Open Test Explorer: Menu 'Test' -> 'Test Explorer'.
2. In the Test Explorer expand sections and find test suite, the same as class name. (E.g.: AllMethod)
3. By using Ctrl + Left mouse select test. (E.g.: AllNumbersAreEven)
4. Click right mouse button -> Select Run/Debug.
5. If test was passed - test will be green, if not - red.
