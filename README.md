# Engineering Workspace: Automation labs & Tools

This repository groups three independent parts. Each folder has its own details — start with the links below.

## Contents

| Folder | What it is |
|---|---|
| [`AutomationTraining_Tasks`](AutomationTraining_Tasks) | The C# automation training course — task stubs to complete for practice (Arrays, Conditions, Loops, Matrix, ToDo, Calculator, games, LINQ, Locators, UI/API test suites). See its [README](AutomationTraining_Tasks/README.md). |
| [`AutomationTraining_Code`](AutomationTraining_Code) | Reference solutions (answers) for the training tasks — the completed counterparts of the projects above (`*_answers`, `ToDoListApplication`, etc.). |
| [`RoadmapConstructor`](RoadmapConstructor) | Interactive roadmap + slide decks. A small web app (Python backend, single-page frontend) that renders from `storage/content.md`. See its [README](RoadmapConstructor/README.md). |

## Where to start

- Practicing the course → open [`AutomationTraining_Tasks`](AutomationTraining_Tasks/README.md).
- Comparing with a working solution → look in [`AutomationTraining_Code`](AutomationTraining_Code).
- Running the roadmap app → follow [`RoadmapConstructor/README.md`](RoadmapConstructor/README.md).
